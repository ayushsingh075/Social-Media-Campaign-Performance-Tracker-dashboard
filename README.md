# Social-Media-Campaign-Performance-Tracker-dashboar
Project Overview-
This project analyzes social media advertising campaign data from platforms such as Facebook and Instagram to evaluate campaign effectiveness, audience engagement, click-through rates (CTR), and return on investment (ROI). The goal is to provide a data-driven view of marketing performance and help optimize future ad strategies.
An interactive dashboard was designed to track key performance indicators, audience demographics, interest groups, and engagement trends over time. The dashboard allows marketers to identify high-performing campaigns and understand user behavior across different audience segments.
Objectives-
Monitor ad campaign performance across multiple interest groups,
Analyze engagement metrics such as clicks, impressions, and CTR,
Evaluate cost metrics including CPC and total ad spend,
Understand audience behavior by age and gender,
Track daily and campaign-wise performance trends,
Support campaign optimization using data insights
